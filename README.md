# klickbox-legal

Public-facing legal pages for the [KlickBox](https://github.com/soltaniehha/KlickBox) iOS app, served via GitHub Pages.

- [Privacy Policy](https://soltaniehha.github.io/klickbox-legal/privacy.html) — required by Apple App Store submission.

To update: edit `privacy.md`, commit, push. GitHub Pages rebuilds within ~1 minute.
